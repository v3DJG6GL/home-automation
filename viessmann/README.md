# Vitodens 200-W B2HB-19 Model Designation


## Model Designation
### B2HB Breakdown:
- **B**  = Boiler (gas-fired condensing boiler)
- **2**  = Series 200 (Vitodens 200-W product line)
- **H**  = Heating only / System boiler 
         (requires separate DHW cylinder for domestic hot water)
         (vs **K** = Kombi/Combi with integrated instant DHW)
- **B**  = Burner variant (MatriX cylinder burner with Lambda Pro Control)

### 19 Suffix:
- **19** = **Heating output capacity in kilowatts (kW)**
         = 19 kW thermal output
         = approximately 64 MBH (64,000 BTU/hour)

### Technical Specifications B2HB-19:
- CSA Input: 12-68 MBH (3.5-20 kW)
- CSA Output: 11-64 MBH (3.2-19 kW)
- Net AHRI Rating: 55 MBH (16 kW)
- Modulation Range: 1:19 (minimum to maximum)
